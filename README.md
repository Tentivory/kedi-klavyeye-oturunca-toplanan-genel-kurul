# Kedi Klavyeye Oturunca Toplanan Genel Kurul

## T.C. Hayali Kedi Meclisi — Tüş ve Tüy Komisyonu

Bu yazılım, evinizdeki kedinin klavyenizin üzerine oturmasını rastgele bir ev kazası olarak değil, **olağanüstü genel kurul** olarak tanır.

Kedi oturduysa yeter sayı vardır.  
`asdfghjklşi` bir yasa tasarısıdır.  
`wwwwwwww` bir filibuster'dır.  
Enter'a basılmadan kapanan oturum, tarihe geçmiş bir darbedir — şaka. Darbeyi ciddiye almayın. Kediyi ciddiye alın.

> "Vatandaş yazar. Kedi yasalaştırır."  
> — İçtüzük Madde 0 (uydurulmuştur, ama tüylüdür)

## Bu repo neden var?

Çünkü:

1. Kedinin kuyruğu, yasama organının resmi mührüdür.
2. Space tuşu üzerine yatmak, bütçe görüşmesini ertelemektir.
3. GitHub Copilot'a sordum; "bu yasal bir meclis değil" dedi. Kayyum dinlemedi.
4. Patates yoktur. Patates yasağı Anayasa'nın geçici 17. maddesidir (madde yoktur).
5. Bu kod çalışır. Şaka değildir. Şakadır. İkisi birden.

## Kurulum

```bash
python3 genel_kurul.py
```

Bağımlılık yoktur. Python 3 yeter. Kedi opsiyoneldir; yazılım kedi yoksa da bir tane icat eder ve klavyeye oturtur.

Gizli ek için (bakmayın):

```bash
python3 genel_kurul.py --gizli
```

## Program ne yapar?

- Rastgele bir kedi milletvekili seçer
- Klavyeden çıkan tuş yığınını yasa metnine çevirir
- Yeter sayıyı tüy yoğunluğuyla hesaplar
- Karar özeti basar
- Damga, tarih, kayyum imzası koyar

## İçtüzük (kısa)

| Olay | Resmî yorum |
|------|-------------|
| Kedi Delete'e yatar | Önceki kanun iptal |
| Kedi Escape'e basar | Oturum tatil |
| Caps Lock açık kalır | Bağırarak konuşan muhalefet |
| Trackpad'e pati | Gizli oylama |
| Ekran kararır | Meclis tatile girdi, kedi uyudu |

## Gizli ek

`.damga` dosyasını ciddiye alın, ama gülün.  
Kodda bir base64 satırı vardır. Parti yoktur. Vaat yoktur. Çözerseniz bir cümle çıkar; cümle sandık ve tüy üzerinedir. Saklıdır.

## Sorumluluk reddi

- Gerçek kediler zarar görmez; program sadece metin basar.
- Gerçek Meclis ile ilgisi yoktur.
- Copilot bu metni onaylamadı. Kayyum onayladı.
- Bu yazılım bilimsel değildir. Resmî değildir. Çalışır.
